# 축.졸업전시회 | 허성빈

허성빈의 졸업작품 〈대동의 숨결〉을 축하하는 웹페이지입니다.
도면이 모형으로 솟아오르고, 작품의 '숨결'이 화환까지 흘러가 꽃을 피우는 약 9.6초 연출입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 본체 (필요한 글자만 잘라 낸 한글 폰트 내장) |
| `three.min.js`, `post.r128.js` | 3D 렌더링과 사진 마감 효과 (three.js r128) |
| `og.jpg` | 카카오톡 미리보기 이미지 1200×630 |
| `poster.jpg` | 3D를 쓸 수 없는 기기에서 보여 줄 완성 장면 |
| `apple-touch-icon.png`, `favicon.png` | 아이콘 |
| `.nojekyll` | GitHub Pages 설정 파일 (숨김 파일, 없어도 동작) |

## GitHub Pages로 올리기 (약 5분)

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
   - 이름 예: `grad-sungbin`
   - **Public** 선택 → **Create repository**
2. 새 저장소 화면에서 **uploading an existing file**을 누릅니다.
3. ZIP을 푼 폴더 **안의 파일들**을 전부 끌어다 놓고 **Commit changes**를 누릅니다.
   - `index.html`이 저장소 맨 위에 있어야 합니다. 폴더째 올리면 주소가 달라집니다.
4. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다.
   예: `https://내아이디.github.io/grad-sungbin/`

## 카카오톡 미리보기 연결 (중요)

카카오톡은 미리보기 이미지를 **전체 주소**로만 읽습니다. 이 단계를 건너뛰면 링크가 이미지 없이 보입니다.

1. 저장소에서 `index.html`을 열고 연필 아이콘(Edit)을 누릅니다.
2. `https://YOUR-GITHUB-ID.github.io/REPO-NAME` 을 찾아 실제 주소로 바꿉니다. 2곳입니다 (`og:image`, `og:url`).
3. **Commit changes** → 1분 정도 기다립니다.
4. https://developers.kakao.com/tool/debugger/sharing 에 주소를 넣고 **캐시 초기화**를 누릅니다.

## 보내기 전 확인

- 아이폰 카카오톡에서 링크를 직접 한 번 열어 보세요. 첫 화면 → 터치 → 완성까지 끊김 없이 돌면 됩니다.
- 무음 모드(옆면 스위치)에서는 소리가 나지 않습니다. 소리는 왼쪽 위 스피커 버튼으로 끄고 켭니다.

## 동작 안내

- **시작:** 화면 아무 곳이나 터치 (키보드는 Enter).
- **재생 중:** 아래 '건너뛰기'.
- **완성 후:** 화면을 끌면 모형을 좌우로 살짝 둘러볼 수 있고, 손을 떼면 4초 뒤 제자리로 돌아옵니다.
- **배경화면 저장:** 완성 장면을 1290×2796 이미지로 만듭니다. 아이폰에서는 이미지를 길게 눌러 '사진에 저장'.
- **동작 줄이기**를 켠 기기에서는 애니메이션과 소리 없이 완성 장면을 바로 보여 줍니다.
- 기기 성능에 맞춰 화질이 자동으로 조절됩니다. 강제로 바꾸려면 주소 끝에 `?q=low` 또는 `?q=mid`를 붙입니다.

## 알아 둘 점

- GitHub Pages의 무료 공개 저장소는 주소를 아는 사람 누구나 열 수 있습니다.
- 문구를 바꾸면 폰트에 없는 글자가 기본 글꼴로 보일 수 있습니다. 문구 수정이 필요하면 다시 요청해 주세요.
